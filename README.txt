GRUPPCENTRALEN 6.1.5 - ANPASSNINGSBAR KLASSRUMSYTA

BYGGD DIREKT PA DEN FUNGERANDE VERSION 6.1.4.

NYTT
- I Bygg klassrum visas ett draghandtag i klassrumsytans nedre hogra horn.
- Dra handtaget for att andra bredd och langd fritt.
- Storleken visas medan handtaget dras.
- Storleken andras i jamna steg om 20 pixlar.
- Mobler och elevplaceringar behaller storlek och position.
- Ytan kan inte minskas sa att befintliga mobler hamnar utanfor.
- Storleken sparas separat for varje klassrum.
- Dubbelklick pa handtaget aterstaller 1000 x 680.
- Handtaget doljs i Placera elever, utskrift och PDF.
- Helskarm och utskrift anvander den sparade klassrumsstorleken.
- Ovrig layout och helskarmsfunktion fran 6.1.4 ar oforandrad.

GRANSER
Minsta storlek: 700 x 500.
Storsta storlek: 2400 x 1800.

INSTALLATION
1. Packa upp ZIP-filen.
2. Ersatt index.html, styles.css och app.js i GitHub-repot.
3. Behall jszip.min.js och service-worker.js oforandrade.
4. Commit och push.
5. Kontrollera att versionsnumret visar 6.1.5.
6. Gor Ctrl+F5.
